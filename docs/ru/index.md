# Документация Unlocker

[ English ](../en/index.md) • [ Русский ](index.md)

> Безопасная автоматическая сетевая разблокировка зашифрованных LUKS-ноутбуков со смартфона Android.
>
> Verified: 2026-08-28 (проверено тестами lab test_unlock.py и релизом Android-клиента)

---

## Добро пожаловать в документацию Unlocker

Unlocker позволяет включать зашифрованный ноутбук или выводить его из гибернации без необходимости вводить длинный пароль с физической клавиатуры. Смартфон подключается к предзагрузочному окружению `initramfs` ноутбука по SSH (через USB-модем, Wi-Fi, Ethernet или удалённый VPS) и безопасно передаёт пароль в LUKS-маппер.

```
 ┌────────────────┐              SSH (Порт 22)             ┌─────────────────────────────┐
 │ Android-клиент │ ──────────────────────────────────────►│ Ноутбук (Initramfs stage)    │
 │                │   Вход по ключу Ed25519 + пароль LUKS  │                             │
 │ • Поиск в сети │                                        │ • SSH-сервер Dropbear       │
 │ • Свои ключи   │                                        │ • /lib/cryptsetup/passfifo  │
 └────────────────┘                                        │ • /dev/mapper/<target>      │
                                                           └──────────────┬──────────────┘
                                                                          │ (Диск открыт)
                                                                          ▼
                                                           ┌─────────────────────────────┐
                                                           │ Переход в основную ОС       │
                                                           └─────────────────────────────┘
```
